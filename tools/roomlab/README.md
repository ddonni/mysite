# 방 사진 → 3D 실험 (roomlab)

2026-11-20 실험이에요. 사이트 기능이 아니고 어디에도 링크되어 있지 않아요.
방 사진을 AI(Claude)가 보고 **방 설계도(JSON)**로 쓰면, 그걸 Three.js로 "내 방을 닮은 미니어처"로 다시 그려 봤어요.

## 여는 법

`index.html`을 브라우저로 열면 돼요(file:// 그대로도 됨). 왼쪽은 원본 사진, 오른쪽은 다시 지은 방이에요.
오른쪽은 끌어서 돌리고 휠로 확대해요.

원본 사진(인터넷 인테리어 예시)은 저작권 때문에 저장소에 넣지 않았어요.
같은 폴더에 `photo.png`를 두면 왼쪽에 보여요.

## 파일

- `room-data.js`: 설계도(`window.ROOM`). 사진을 보고 쓴 2차 결과예요.
  1차에서는 책상 위치를 잘못 읽어서, 렌더 화면을 사진과 나란히 비교한 뒤 고쳤어요.
- `render.js`: 설계도를 장면으로 그려요. 좌표·도형 규칙은 맨 위 주석에 있어요.

## 설계도 형식 (요약)

- 단위는 미터예요. 원점은 방 바닥 가운데이고, x는 오른쪽, y는 위, z는 앞(카메라 쪽)이에요.
- 벽은 뒷벽(z = -d/2), 왼벽, 오른벽 셋이에요. 앞은 열려 있어요.
- 필드:
  - `room`: `{ w, d, h, wall, walls?, trim, floor:{color, pattern: wood|tile|carpet|plain} }`
  - `openings`: `[{ wall, kind: window|door, x, y, w, h }]`
  - `objects`: `[{ name, x, z, rot, parts:[{ shape: box|cylinder|sphere|cone, pos, size, color, rot?, emissive? }] }]`
  - `camera`(사진과 비슷한 시점), `ambient`, `sun`, `light`, `lamps`(켜진 조명)

## 알게 된 것 · 다음 단계

  우리 쪽 AI 비용이 들지 않아요.
